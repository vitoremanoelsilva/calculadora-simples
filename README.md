# 🧮 Mini Calculadora Web

Um projeto simples e interativo de uma calculadora web desenvolvida com **HTML5**, **CSS3** e **JavaScript**. Criado para praticar a estruturação de projetos web em ficheiros separados e manipulação do DOM.

---

## 🚀 Tecnologias Utilizadas

Neste projeto foram utilizadas as seguintes tecnologias:

- **HTML5**: Estrutura e elementos da página.
- **CSS3**: Estilização, layout responsivo e tema escuro (*dark mode*).
- **JavaScript**: Lógica das operações matemáticas e interatividade.
